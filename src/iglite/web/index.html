        Monitor every device on your network

        This tab shows each device behind your internet gateway: what it connects to, which sites it looks up, and anything flagged. It needs gateway mode. Start IntelGraph Lite on the machine your traffic goes through, for example:

        • Ubuntu laptop as a Wi-Fi hotspot: sudo -E iglite serve --conntrack --tail /var/log/hotspot-dns.log (or run scripts/gateway-hotspot.sh to set everything up)
        • Router you can log in to: iglite serve --ssh root@192.168.1.1
        • Router or firewall that sends logs: iglite serve --syslog 5514 --netflow 2055
        • Pi-hole: iglite serve --tail /var/log/pihole/pihole.log

        Right now IntelGraph Lite is watching this computer only (see Live network).
